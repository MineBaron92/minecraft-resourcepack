# 캐릭터 2: PSD 입력 → Spine 4.2 (idle + 바스트 모핑)

입력: `assets/char2/` (See-through PSD, depth PSD, 분리 전 원본 `reference/original.png`). 원본은 수정 없이 보존했습니다.
재생성: `NODE_DIR=... bash spine_pipeline/run_char2.sh`

## 결과물
| 경로 | 내용 |
|---|---|
| `spine/character.json`, `.atlas`, `.png`, `images/` | Spine 4.2 (본 39, 슬롯 22, 물리 제약 20) |
| 애니메이션 | `idle`, `bust_bounce`, `jump_cheer` (+ 각 `_physics` 버전) |
| `preview.html`, `preview_offline.html` | 공식 Spine Web Player 미리보기 (기본 애니메이션 `bust_bounce`) |
| `verification/` | mp4, webp, gif, 가중치 맵, 검증 보고서 |

## 1단계: PSD 가져오기 (`psd_import.py`)
- 레이어 위치를 PSD에서 그대로 읽어서, 1번 캐릭터 때의 위치 탐색이 필요 없습니다. 빈 레이어 7개는 제외해서 22장을 씁니다.
- 드로우 오더는 PSD 순서에서 출발해, 원본 이미지와 비교하는 렌더 오차 탐색으로 다듬었습니다. 바뀐 건 신발을 양말 위로 올린 것 하나입니다.
- 뒷머리 분리를 시도했지만, 앞머리까지 함께 고려하니 얼굴 앞으로 나오는 뒷머리 픽셀이 없었습니다. 그래서 뒷머리는 한 장으로 유지했습니다.
- 원본 대비 PSNR은 24.8 dB, 실루엣 IoU는 0.976, SSIM은 0.971입니다. 전역 위치 오차는 1px 미만이고, 남은 차이는 See-through가 선화를 다시 그리면서 생긴 것입니다(밝기 +5 정도). 배치를 바꿔서 줄일 수 있는 오차가 아닙니다.

## 2단계: 리깅 (`rig_char2.py`, 공용 기능은 `rig.py` 재사용)
- 포니테일 3본과 정수리 삐침 1본, 앞머리·옆머리 3본, 가디건 앞자락 2본, 플리츠 치마 3본을 넣었습니다.
- 팔은 소매 레이어의 주축(PCA)에서 어깨→팔꿈치→손을 잡았고, 다리는 허벅지와 정강이로 나눴습니다.
- **발 고정**: 다리는 hip → 허벅지 → 정강이 순서로 이어집니다. 엉덩이가 내려가면 다리를 길이 방향으로 압축해서 신발이 미끄러지지 않습니다(점프 때는 다리가 몸과 함께 뜹니다).
- **가슴**: 이 캐릭터는 블러시가 없고, 가디건이 앞에 있어 depth 값도 평평했습니다. 그래서 흰 니트 탑 영역에서 중심을 잡았습니다(립 줄무늬로 쪼개진 영역을 합쳐서 계산). 좌우 2본 구조와 소프트바디 물리는 1번 캐릭터와 같습니다.

## 3단계: 애니메이션
- `idle`(8초): 호흡, 몸 흔들림, 머리의 지연 움직임, 팔 흔들림, 깜빡임. 포니테일·앞머리·가디건·치마는 스프링으로 따라 움직입니다.
- `bust_bounce`(6.4초): 무릎을 살짝 굽혔다 펴는 바운스 2회. 발은 고정이고, 떨림을 고친 C1 곡선을 그대로 씁니다.
  - 가슴 끝 변위는 최대 약 5px, 스트레치는 0.87~1.19입니다.

## 점프 + 만세 (`jump_cheer`, 2.8초)
- 흐름: 0.30~0.62초 웅크림(엉덩이 26px 하강, 팔을 뒤로) → 0.74초 도약 → 포물선으로 비행, 1.05초 최고점 72px → 1.36초 착지 → 1.52초 무릎으로 받기 → 다시 서서 대기.
- 팔은 대각선 위까지 올립니다(약 105°). 공중에서는 몸이 옆으로 살짝 치우쳐 좌우 흔들림이 달라지고, 고개를 갸웃합니다. 착지 직후 한 번 깜빡입니다.
- 다리: 처음에는 IK로 무릎을 옆으로 굽혔는데 O자 다리처럼 보였습니다. 정면 구도에서 웅크림은 다리가 짧아 보이는 원근(무릎이 카메라 쪽으로 나옴)으로 읽히기 때문에, 허벅지와 정강이를 길이 방향으로 압축하는 방식으로 바꿨습니다. 압축한 허벅지는 약간 넓혀 부피를 유지합니다. 땅에 있는 동안 발은 정확히 고정되고, 공중에서는 정강이를 살짝 접어 무릎을 당긴 느낌을 냅니다.
- 2차 모션: 머리카락, 치마, 가디건에 길이 방향 스프링을 새로 넣었습니다. 수직으로 늘어진 가닥은 회전 스프링만으로는 위아래 움직임에 반응하지 않기 때문입니다. 도약할 때 늘어나고 공중에서 떠오르며 압축된 뒤, 착지 때 출렁입니다.
- **팔 자연스러움 개선** ("종이 인형 같다"는 피드백 반영):
  - 쇄골 본 추가: 팔을 들면 어깨와 가디건 어깨선이 함께 올라가서, 겨드랑이 한 점에서 도는 핀 관절 느낌이 사라졌습니다.
  - 팔꿈치 아크: 팔을 들어 올리는 중간에 팔꿈치가 가장 많이 굽고, 최고점에서는 거의 펴집니다.
  - 겹침 동작: 아래팔과 손(손목 본 추가)이 위팔을 뒤따라오는 스프링을 키 동작 위에 더했습니다. 고정 게인으로 실제 관성에 가깝게 반응합니다.
  - 비대칭: 왼팔이 0.05초 늦고 크기는 94%라, 거울처럼 똑같이 움직이지 않습니다.
  - **어깨 탈골 수정** (다음 피드백 반영):
    - 회전 축(피벗) 이동: 축이 소매 맨 윗가장자리에 있어서, 팔을 들면 소매 뿌리가 어깨선 위로 튀어나왔습니다. 축을 몸통 실루엣 안쪽(팔 폭의 0.18만큼 아래, 0.45만큼 안쪽)으로 옮겨서 이음매가 가디건 어깨 밑에 숨게 했습니다.
    - 삼각근 보조 본: 가디건의 어깨 끝 부분만 팔을 따라가게 해서, 천이 소매 뿌리를 덮으며 늘어납니다. 범위를 좁게 잡아 흰 탑과 옆선은 영향을 받지 않습니다.
    - 원인을 키우던 요소 제거: 어깨 들림을 9°에서 3°로 줄이고, 위팔 원근 축소는 없앴습니다.
    - 팔 높이 조정: 최고점을 약 76°로 낮췄습니다. 2D 컷아웃 팔은 80°를 넘으면 소매 뿌리가 어깨선 위로 드러납니다. 손그림 리그라면 그 지점에서 "들어 올린 어깨" 그림으로 교체합니다.
  - 공용 `rig.py`: 스프링이 키 애니메이션을 덮어쓰지 않고 그 위에 더해지도록 바꿨고(`FIXED_GAIN` 추가), 다른 캐릭터에도 쓸 수 있습니다.
- 수정한 문제: 팔을 들면 가디건 옆선에 톱니 모양이 생겼습니다. 상의 메쉬에 넣어 둔 위팔 가중치가 원인이라 제거했습니다.
- 검증: 최대 떨림 2.13(팔 개선 전 2.82)은 0.63초의 도약 순간이고 의도한 폭발적인 출발입니다. 루프 이음매는 0.01입니다.
- 한계: 팔은 약 76°까지만 올립니다. 그보다 높이 들려면 들어 올린 어깨를 그린 원화가 따로 필요합니다. 손 모양과 입 모양은 고정입니다.

## 검증
- 공식 spine-webgl 4.2로 렌더링했고 로딩 오류는 0건입니다. setup pose와 1단계 합성의 차이는 57.7 dB로 사실상 같습니다.
- 바스트 영역의 최대 떨림은 1.87(착지 순간)이고, idle에서는 0.19입니다.

## 한계
- 원화가 1024px라 눈 같은 작은 부품의 디테일에 한계가 있습니다. 2048px 이상을 권장합니다.
- 소매와 손이 한 레이어여서 손가락은 움직이지 않습니다.
- 니트 탑 줄무늬와 가디건이 상의 레이어에 합쳐져 있어, 가슴 주변에서 함께 늘어납니다.
